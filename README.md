# 门窗管理软件

**瘦核心 + 插件架构**的门窗管理桌面软件。纯 Rust 单一 exe,Apache 2.0 开源,不歧视任何使用领域(允许同行商业使用与开发闭源插件)。

## 运行

双击 `门窗管理软件.exe` 即可运行。**无需安装 Node、无需浏览器、无需联网**,数据全部保存在软件目录下(D 盘)。

## 功能模块

- **订单管理**:订单状态流转(未合并 → 待审核 → 待生产 → 生产中 → 成品 → 已出库),支持搜索、按状态筛选、状态统计看板。
- **新增订单**:录入订单号、合同号、客户、终端地址、料型、产品名称、尺寸(宽×高)、颜色、面玻、背玻、款式、订单总价、备注,以及型材 / 玻璃 / 配件明细。
- **合同管理**:合同号、合同日期、客户、合同总价、已付款、抹零、尾款、产品名称、物流、物流单号、合同标记。
- **客户管理**:客户档案(名称、电话、联系人、品牌、地址、终端地址、备注),新增订单时可直接选择。
- **打印中心**:生产单 / 结算单 / 下料单 / 玻璃厂单 / 领料单 / 合片单 / 回执单 / 标签,打印前强制尺寸核对。
- **生产进度**:按订单跟踪下料 / 组框 / 玻璃 / 合片 / 包装 / 入库等环节。
- **插件管理**:内置算料示例插件,通过标准 PluginApi 注册 Hook。
- **备份管理**:三套独立备份(关闭前 / 定时快照 / 手动)。
- **系统设置**:公司名称、默认操作员。

## 架构

- **内核(瘦核心)**:本地数据读写(SQLite)、订单实体、基础打印调度、插件加载与权限管理。
- **插件**:算料、下料优化、报表、进销存、结算等全部以插件实现;自研功能与第三方插件使用相同 API。
- **版本化 Hook**:`order.saved`(订单保存后)、`print.before`(打印前)、`print.after`、`size.confirmed`(尺寸确认后)。

技术栈:Tauri v2(Rust)+ rusqlite(内置 SQLite,无需外部依赖)。

> 合规说明:本项目代码 100% 自主编写,仅借鉴门窗行业通用业务概念(订单、型材、玻璃、下料、生产环节等通用术语,不受版权保护),不复制任何第三方专有代码;采用 Apache 2.0 宽松许可证,可放心开源与二次开发。

## 三套独立备份(默认压缩)

| 类型 | 触发 | 目录 |
|---|---|---|
| 关闭前备份 | 优雅退出时 | `backup/shutdown/` |
| 定时快照 | 按设定间隔(VACUUM INTO) | `backup/snapshot/` |
| 手动备份 | 用户一键触发 | `backup/manual/` |

三套目录独立、独立保留策略,默认压缩为 `.sqlite.gz`,文件名含时间戳与类型。

## 打印与尺寸确认

- 生产单、下料单、玻璃厂单、领料单、结算单/销售单、标签、回执单、合片单,均支持单独预览/打印/导出,也支持按订单合并。
- 打印前强制尺寸核对页:列出原始/实际尺寸、型材类型、数量,异常高亮;必须勾选「尺寸已核对」后才能打印。
- 打印模板包含:订单号、客户、产品、料型、颜色、尺寸、面玻、背玻、终端地址,以及型材明细表、玻璃明细表。

## 编译(可选)

需要 Rust 工具链 + MSVC Build Tools:

```bash
cd src-tauri
cargo build --release
```

产物在 `src-tauri/target/release/door-window-manager.exe`。
